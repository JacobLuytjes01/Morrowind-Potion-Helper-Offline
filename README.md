# Morrowind Potion Helper (Offline)
A web tool designed to help people find the right ingredients for potion recipes in The Elder Scrolls III: Morrowind.

Built with HTML, CSS, and JavaScript.

## Features
**Offline Functionality**

**Light Mode and Dark Mode**

## How to Run the Tool
Open the index.html file in your browser.
